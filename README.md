# Steven Gerbitz — Professional Portfolio

A responsive professional portfolio intended for **steven.gerbitz.org**.

## Contents

- About — technical background and professional approach
- Expertise — enterprise IT, telecommunications, wireless broadband, mentoring, and quality
- Career — expandable employment timeline and accomplishments
- Projects — independently directed, AI-assisted product and UX work
- Values — service, accountability, and technical standards

The design uses subdued charcoal, warm cream, burgundy, and silver. It requires no paid framework, external font, tracker, or analytics.

## Preview locally

Open \`index.html\` in a web browser. The site consists only of \`index.html\`, \`styles.css\`, and \`script.js\`.

## Enable GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main**, folder **/(root)**, then **Save**.
4. After deployment, the initial review site should be available at https://stevenpgerbitz-del.github.io/stevengerbitz/ .

## Custom domain — later

Once the initial website design is ready, set up **steven.gerbitz.org** as the custom domain in GitHub Pages and create the corresponding DNS entry. Do not change the domain's existing mail records. If desired, the apex **gerbitz.org** can then redirect to the portfolio.

The \`CNAME\` file is intentionally not present yet because custom-domain routing has not been set up.

## Content policy

This is a working public portfolio, not an exhaustive résumé. The descriptions reflect the owner's verified work history, distinguish individual assignments from team participation, and describe independent software projects accurately as AI-assisted collaborations. Public contact details and downloadable résumés will be added when the owner selects them.
